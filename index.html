Raw Code Catalogue

Four anonymised codebase portfolios available as raw training data. Each source is listed with what the code is, how it was measured, and full per-repository metadata. Click any row to expand every recorded field.

Anonymisation. Seller, client, brand and product names, people, repository names, URLs, file paths and report hashes have been removed. Repositories carry catalogue IDs (A-001, B-01, D-01; source C keeps its own R-/F-/P- aliases). Descriptions name only public third-party technologies.
Counting. Each source was measured by a different method, described in its section. Line counts are not directly comparable across sources, and source C's yearly line counts must not be added together.
Language support (i18n). Repositories are flagged as multi-language or single-locale only where the project documentation says so (currently 5, all in source D). Every other repository reads "not documented"; this means the reports are silent, not that the code is English-only. A scan of each repository for locale and translation files can confirm this before delivery.
Before delivery. Transfer rights, removal of historical secrets and personal data, and exact delivery revisions are confirmed per source before code is shared.
